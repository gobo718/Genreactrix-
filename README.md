# Genreactrix v0.9.2v — Folded-Landscape Workspace Polish

Canonical source: v0.9.2u.

This release is narrowly scoped to the Galaxy Z Fold6 folded-landscape layout.

## Home Image Console
- Keeps the image viewport as a true square with no stretched blank area.
- Keeps the image left-aligned.
- Keeps the AI freeform description beside the image with vertical scrolling only when needed.
- Removes AI primitive/reaction percentages from the folded-landscape Home page.
- Leaves the Director Console unchanged.

## AI Console
- Places Primitive Suggestions and Theme Suggestions side by side.
- Places the AI freeform description across the full width below them.
- Compacts spacing to target a single folded-landscape screen without page scrolling.
- Preserves all AI percentages and analysis data inside the dedicated AI Console.

## Preserved
- One-piece 13×13 landscape matrix.
- 85% shared matrix font / 15% individual shrink behavior.
- Portrait, tablet, desktop, storage, and state behavior.
- Standard four-file package.
